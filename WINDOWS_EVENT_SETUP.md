# Interactive Surface — установка на Windows и управление с телефона при закрытой крышке

**Актуальная версия 0.4.1 находится в `main`.** Калибровка, распознавание, шарики, веб-пульт и Windows-подготовка доступны после обычного клонирования репозитория — ветку указывать не нужно.

Цель: установить приложение на Windows-ноутбук, подключить USB-камеру и проектор, связать телефон с локальным веб-пультом, закрыть крышку ноутбука и продолжить настройку и игру с телефона.

> ВАЖНО: ноутбук должен **продолжать работать**. Закрытая крышка — не сон и не выключение. Не убирай работающий ноутбук в сумку, закрытый ящик или кофр без вентиляции.

## 1. Установить Git и Python на Windows

Используй **Windows 11** (для Windows 10 шаги аналогичны). Открой **Командную строку (cmd)** через меню «Пуск». Если Git или Python отсутствуют, установи их через `winget` (если он доступен):

```cmd
winget install --id Git.Git -e
winget install --id Python.Python.3.12 -e
```

Закрой командную строку и открой её снова. Проверь:

```cmd
git --version
py -3.12 --version
```

Желательно использовать Python **3.12**: для него доступны необходимые готовые пакеты.

## 2. Скачать правильную версию проекта

В обычной командной строке Windows (`cmd`) выполни:

```cmd
cd /d "%USERPROFILE%"
git clone https://github.com/Baryshnikovae/interactive-surface.git
cd interactive-surface
start.bat
```

Авторизация GitHub не требуется: репозиторий пока публичный.

При первом запуске `start.bat` создаёт виртуальное окружение и устанавливает библиотеки, затем запускает сервер. В последующие разы используем тот же `start.bat`.

На ноутбуке должна открыться панель `http://127.0.0.1:8765`. В окне терминала будет показан локальный IP и **QR-код с ключом оператора**.

**Не закрывай терминал!** Закрытие окна остановит сервер, и управление с телефона пропадёт.

## 3. Подготовка ноутбука к закрытию крышки

Сначала подключи питание от сети, USB-камеру и проектор. На мероприятии лучше постоянно использовать блок питания.

### Дисплей / проектор

На ноутбуке нажми **Win + P** и выбери **«Только второй экран»** (`Second screen only`). Это удобный режим: проектор остаётся основным видимым экраном, даже когда крышка закрыта.

Если этот режим не подходит конкретному ноутбуку, выбери «Расширить», а экран проектора укажи вручную в Interactive Surface.

**Режим вывода настроить до калибровки**: при смене экранов могут измениться идентификаторы и разрешение, что потребует повторной калибровки.

### Питание — что делать при закрытии крышки

В Windows открой:

**Панель управления → Оборудование и звук → Электропитание → Действия при закрытии крышки.**

Для режима **«От сети»** выставь **«Действие не требуется»**. Сохрани изменения.

Далее: **Параметры → Система → Питание и батарея → Время ожидания экрана, сна и гибернации**. Для питания от сети отключи автоматический переход в сон и автоматическое отключение экрана на время мероприятия. Названия пунктов могут немного отличаться в разных версиях Windows.

Следи, чтобы заставка или политика блокировки Windows не переключали проектор на экран входа. Не используй `Win + L` во время показа.

### Сеть и брандмауэр

Ноутбук и телефон должны быть в одной **доверенной локальной сети** (роутер/точка доступа; интернет после установки необязателен). У Wi-Fi сети на Windows выбери профиль **«Частная сеть»**: Параметры → Сеть и Интернет → Wi-Fi → свойства подключённой сети.

Для доступа с телефона нужно разрешить входящие соединения по **TCP 8765** только в профиле **Private/Частная**. Ниже есть скрипт, который делает это автоматически.

Гостевые сети и некоторые точки доступа изолируют клиентов друг от друга. Если телефон не видит ноутбук, даже когда оба подключены к Wi-Fi, проверь, отключена ли `AP/client isolation`.

### Самый простой вариант — скрипт подготовки Windows

В папке проекта есть `prepare-event-windows.bat`. Перед мероприятием:

1. Открой папку `%USERPROFILE%\interactive-surface` в Проводнике Windows.
2. Найди `prepare-event-windows.bat`.
3. Нажми правой кнопкой → **«Запуск от имени администратора»**.
4. Разреши системные изменения.

Скрипт изменит для **текущей схемы электропитания только режим «От сети»**: закрытие крышки — ничего не делать; отключит таймеры сна, гибернации и отключения дисплея. Также создаст правило брандмауэра для TCP 8765 **только в частной сети**. Работа от аккумулятора не меняется.

Это **изменения Windows на уровне ноутбука**, не только приложения. После мероприятия верни прежние параметры питания вручную через панель управления. Созданное правило брандмауэра при желании можно удалить через **PowerShell от имени администратора**:

```powershell
Remove-NetFirewallRule -Name InteractiveSurface-LAN-8765
```

Если ноутбук управляется организацией, Windows может не позволить изменить параметры без соответствующих прав.

## 4. Подключить телефон — ДО закрытия крышки

1. Запусти `start.bat` и оставь окно командной строки открытым.
2. Подключи телефон к **той же Wi-Fi сети**.
3. Отсканируй QR-код **в терминале Windows**. В QR содержится адрес ноутбука и временный ключ для веб-пульта.
4. Проверь, что с телефона открываются «Калибровка», «Распознавание», «Объекты» и «Игры».
5. Выполни тестовое действие с телефона и посмотри, что изменилось в приложении или на проекторе.
6. **Только теперь закрывай крышку**. Проверь, что телефон по-прежнему управляет программой, а проектор продолжает выводить изображение. Если дисплей пропал — открой крышку и проверь режим Win+P и настройки питания.

Адрес `127.0.0.1` работает **только на самом ноутбуке**. На телефоне нужен адрес ноутбука в локальной сети (например, `http://192.168.1.42:8765`). Автоматически сгенерированный QR укажет этот адрес и ключ.

Ключ генерируется **заново при каждом запуске сервера**. После перезапуска приложения нужно заново открыть панель по свежему QR.

**Нельзя убирать работающий ноутбук в сумку или герметичный кофр.** Ставь на устойчивую поверхность с открытыми вентиляционными отверстиями. С закрытой крышкой некоторые модели перегреваются или отключают внешние устройства.

## 5. Вся дальнейшая работа с телефона

Открой разделы веб-пульта:

- `/` — выбрать камеру и проектор, совместить четыре точки камеры и четыре точки проекции, проверить сетку.
- `/recognition` — выбрать чёрный/белый фон, сделать снимок, выделить стикеры четырьмя углами; исключить лишние цвета, сохранить.
- `/tracking` — посмотреть зелёные прямоугольники найденных элементов.
- `/games` — запустить шарики, настроить лунку, цвет, размер, графику и режим перезапуска раундов.

Проектор показывает игру на выбранном экране. **Телефон — это пульт, а всю физику, захват камеры и отрисовку продолжает выполнять ноутбук.**

Калибровка и цвет сохраняются локально вне папки GitHub и могут восстанавливаться при той же камере, проекторе и разрешениях. Токен веб-пульта не сохраняется между запусками.

## 6. Как запускать потом

После первой установки открой обычный `cmd`:

```cmd
cd /d "%USERPROFILE%\interactive-surface"
start.bat
```

Для обновления версии, когда сервер остановлен:

```cmd
cd /d "%USERPROFILE%\interactive-surface"
git pull --ff-only
start.bat
```

Если обновление изменило Python-зависимости, можно переустановить их:

```cmd
.venv\Scripts\python.exe -m pip install -e ".[windows]"
```

Остановить сервер — **Ctrl+C** в его командной строке.

## 7. Если что-то пошло не так

**Телефон не видит сервер.** Проверь сеть на обоих устройствах, командой `ipconfig` узнай IP ноутбука, убедись в профиле «Частная сеть», правиле TCP 8765, отсутствии VPN или изоляции клиентов. Если приложение выбрало не тот интерфейс, перезапусти его с правильным IP (значение ниже пример):

```cmd
start.bat --lan-ip 192.168.1.42
```

**Закрыл крышку — пропала проекция.** Проверь «Действие не требуется», отключение сна, Win+P → «Только второй экран», настройки видеодрайвера и физическое подключение HDMI/USB-C. Некоторые ноутбуки или корпоративные политики могут ограничивать работу с закрытой крышкой.

**QR не сохранился на телефоне.** Если сервер не перезапускался, достаточно той же уже подключённой вкладки на телефоне. После перезапуска нужен новый QR.

**Погас экран из-за автоблокировки.** Вернись к ноутбуку и проверь таймеры, экранную заставку и политики блокировки. Не пытайся обойти корпоративные ограничения.

**Камера отключилась.** Проверь кабель/USB-питание, затем повторно выбери камеру в веб-интерфейсе.

**Безопасность:** не открывай порт 8765 в интернет и не показывай QR-код посторонним. Это локальный HTTP-сервис с токеном, не защищённый TLS от прослушивания недоверенной Wi-Fi сети.
